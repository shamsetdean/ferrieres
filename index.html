Ajouter des photos

Les photos sont des fichiers statiques stockés dans le dépôt GitHub. Pour ajouter une photo à un bâtiment :

1. Déposer le fichier dans :
  photos/[id-du-batiment].jpg

2. Dans data.js, mettre à jour :
  photo: "mairie-annexe.jpg"

Formats acceptés : jpg, jpeg, png, webp
